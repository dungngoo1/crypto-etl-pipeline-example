Dự án xây dựng pipeline ETL (Extract, Transform, Load) sử dụng Python để thu thập dữ liệu giá tiền điện tử từ Binance API.
Dữ liệu thô được lưu trữ dưới định dạng JSON, hỗ trợ kiểm tra và truy xuất dữ liệu sau khi thu thập.
Pipeline thực hiện xử lý lỗi API, quản lý cấu hình bằng file .env và tổ chức mã nguồn thành các module riêng biệt.
Dự án giúp thực hành quy trình ingestion dữ liệu, lưu trữ dữ liệu thô và xây dựng nền tảng cho các bước biến đổi, phân tích dữ liệu tiếp theo.
